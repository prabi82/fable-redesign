# Industry Pack — Construction & Engineering

**Slug:** `construction-engineering`
**Use for:** Contractors, civil engineering, architecture firms, MEP, infrastructure

## Visual codes

- Technical drawings, dimension lines, blueprint grids, section markers
- Hard hat / steel beam as subtle motif — not cartoon icons
- Project phase numbering (01 Survey → 04 Handover)

## Palette tendencies

- Concrete gray `#8B9199`, steel blue `#2D4A6F`, safety orange accent sparingly
- Light technical drawings on off-white `#F4F2EF`
- Dark blueprint theme only if brand uses it

## Avoid

- Luxury hospitality aesthetics
- Soft pastels; playful illustrations
- Generic "building" clip art

## Typography (vetted pairings)

1. Archivo + Bitter — technical editorial
2. Space Grotesk + IBM Plex Sans — engineering modern
3. Outfit + Source Serif 4 — project portfolio

## Signature scene ideas

- Scroll-drawn blueprint path through project phases
- Horizontal gallery: completed projects
- Data-panel hero: project stats (sqm, years, sectors)

## Imagery keywords

`construction site`, `steel structure`, `bridge engineering`, `architectural blueprint`
Picsum IDs: 1059, 1060, 1062

## Copy voice

Capable, precise, project-focused. Lead with capability and completed work.
"Request a proposal" / "View projects".

## Concept examples

- **Technical drawing** — hairline grid, dimension annotations, monospace labels
- **Project dossier** — indexed portfolio, alternating full-bleed site photos
- **Infrastructure registry** — bento grid of sectors served

## One action default

Request proposal / Contact project team
