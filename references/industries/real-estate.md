# Industry Pack — Real Estate

**Slug:** `real-estate`
**Use for:** Property developers, agencies, brokers, luxury homes, commercial real estate

## Visual codes

- Full-bleed property photography, floor plan hints, location coordinates
- Oversized numerals for price/sqm/bedroom counts
- Map integration or coordinate strings as flourish

## Palette tendencies

- Warm neutrals `#F5F0EB`, charcoal `#2B2B2B`, one accent (terracotta, forest, navy)
- Luxury: deep charcoal + cream + gold ONLY when brand already luxury
- Commercial: cooler grays, institutional blue accents

## Avoid

- Generic three-property cards in a row as entire page
- Clip art houses; emoji keys
- Dark tech SaaS aesthetics

## Typography (vetted pairings)

1. Cormorant Garamond + Lato — luxury editorial
2. Playfair Display + Source Sans 3 — high-end listings
3. Syne + IBM Plex Sans — modern developer

## Signature scene ideas

- Horizontal scroll property gallery
- Scrollytelling: property features with sticky imagery
- Full-bleed hero with low-left text over aerial

## Imagery keywords

`luxury home interior`, `modern architecture`, `apartment living`, `aerial property`
Picsum IDs: 1067, 1068, 1074

## Copy voice

Aspirational but factual. Location, specs, lifestyle in short lines.
"Schedule a viewing" / "Download brochure".

## Concept examples

- **Property editorial** — magazine layout, one listing per chapter
- **Development portfolio** — bento grid varying sizes by project importance
- **Location atlas** — coordinates, neighborhood context, map flourish

## One action default

Schedule viewing / Inquire about property
