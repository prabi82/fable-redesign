# Industry Pack — Tech & SaaS

**Slug:** `tech-saas`
**Use for:** Software products, startups, IT services, agencies, dev tools

## Visual codes

- Product UI mockups, code snippets as texture (subtle), geometric precision
- Feature indexing with monospace labels, not three equal icon cards
- Dark OLED themes ONLY when product/brand is already dark

## Palette tendencies

- Restrained: near-black `#050505` + one accent OR clean white + one accent
- No default purple/indigo/cyan gradients
- Accent from brand: green, blue, orange — one only

## Avoid

- Floating blob illustrations
- "AI glow" rainbow gradients
- Generic dashboard screenshots as hero
- Inter as display type

## Typography (vetted pairings)

1. Syne + IBM Plex Sans — product modern
2. Space Grotesk + Source Sans 3 — dev tool
3. Outfit + Source Serif 4 — humanized SaaS

## Signature scene ideas

- Product scrollytelling with sticky UI mockup
- Horizontal feature gallery
- Data-panel hero: live metrics, pricing tier

## Imagery keywords

`minimal workspace`, `abstract tech`, `software interface`, `team collaboration`
Picsum IDs: 180, 326, 367

## Copy voice

Clear, confident, jargon-free. Lead with outcome not feature list.
"Start free trial" / "Book a demo" / "See pricing".

## Concept examples

- **Product dossier** — sticky product frame, scrolling feature beats
- **Precision instrument** — hairline grid, monospace labels, restrained motion
- **Human software** — editorial photography + minimal UI overlays

## One action default

Start trial / Book demo
